# Notatki

## Osoby z klasy

Na tej stronie na której teraz jesteś, gdzieś powinna być opcja żeby wyszukać tekst.
Notatki są podzielone na przedmioty i posortowane chronologicznie.
W razie problemów napisz do mnie.

Jeśli chcesz pomóc lub masz pomysł jak mogę coś poprawić, proszę napisz.
