# Tkanka mięśniowa

Cechy tkanki mięśniowej:

- Duża ilość miofibryli (Włókna kłuczliwe, zbudowane z aktyny i miozyny)
- Włókniste komórki
- Zdolność do skurczu

Rodzaje tkanki mięśniowej:

| cecha                               | Poprzecznie prążkowana               | Poprzecznie prążkowana serca | Gładka                                     |
| ----------------------------------- | ------------------------------------ | ---------------------------- | ------------------------------------------ |
| Kształt włókien                     | Wydłużony, cylindryczne, tępo ścięte | Wydłużone, rozgałęzione      | Wydłużone, wrzecionowate, ostro zakończone |
| Ułożenie miofibryli                 | Regularne                            | Regularne                    | Nieregularne                               |
| Prążkowanie                         | Tak                                  | Tak                          | Nie                                        |
| Ilość jąder komórkowych i położenie | Bardzo wiele, peryferycznie          | Jedno, centralnie            | Jedno, centralnie                          |
| Zależność skurczu od woli           | Zależne                              | Niezależne                   | Niezależne                                 |
| Siła skurczu, wytrzymałość          | Duża, mała                           | Słabsza, duża                | Słaba, brak męczenia                       |
| Przykład występowania               | Biceps                               | Serce                        | Żołądek                                    |
