# General

One subject = One notes directory in `docs/` directory, named after the subject

In a subject directory, notes follow `YYYY-MM-DD-short-name.md` naming schema

All assets live in the `assets/` directory, with original file names

# Commits

Commits follow relaxed, modified conventional commits conventions.

Allowed subjects:
- `ci` for changes in workflows
- `code` for other changes in code
- `docs` for changes in documentation
- `[SUBJECT_NAME]` for each lesson

Commit after each lesson. You should never turn off the laptop without commiting.
